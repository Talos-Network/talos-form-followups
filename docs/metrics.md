Measured the morning the first real nudges went out, so this is the
untouched "before" picture. One report received after the first nudges
(Alina's supervisor, 26 Aug) is discounted from these numbers.

**Method.** For every placement with Expected Reports > 0 (n=51): completion
= reports submitted / reports expected. The headline number is CAPPED —
each placement contributes at most its expected count, so one person's
over-submission can't mask another's gap. Raw (uncapped) shown for
reference. Re-measure with `python3 scripts/completion_stats.py`.
